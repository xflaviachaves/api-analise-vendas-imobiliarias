# API de Análise e Gestão de Vendas Imobiliárias

API REST desenvolvida em Node.js com Express para consulta, processamento e agregação de métricas de vendas do setor imobiliário, incluindo documentação interativa via Swagger.

---

## Sobre o Projeto

Este projeto consiste numa solução de backend concebida para estruturar e disponibilizar dados operacionais e analíticos de transações imobiliárias. O sistema processa conjuntos de dados para gerar indicadores de negócio, tais como a distribuição percentual de vendas categorizadas por tipo de imóvel.

### Principais Funcionalidades
- **Agregação e Análise de Dados:** Rotas especializadas no cálculo de métricas consolidadas (ex.: volume e percentual financeiro por categoria de imóvel).
- **Integração via API REST:** Disponibilização de endpoints estruturados com respostas em formato JSON.
- **Documentação Interativa:** Mapeamento completo dos endpoints através de especificação OpenAPI/Swagger UI.
- **Tratamento e Consistência de Dados:** Validação de entradas e manipulação lógica de dados numéricos e textuais.

---

## Tecnologias Utilizadas

- **Ambiente de Execução:** Node.js
- **Framework Web:** Express
- **Documentação de API:** Swagger UI (`swagger.yaml`)
- **Controlo de Versão:** Git & GitHub
